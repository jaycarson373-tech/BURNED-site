# Topblast interface direction

The production interface uses one deep emerald trading surface, thin borders,
off-white financial typography and lime only for primary actions and positive
market state. Coral remains reserved for underwater positions.

Reference review:

- 21st.dev Web3 Bento: compact live metrics and explicit data hierarchy. The
  Topblast implementation keeps the density and hierarchy while avoiding its
  decorative card stack.
- 21st.dev Stock Market Tracker: chart-first responsive control grouping. The
  existing TradingView Lightweight Charts implementation remains in place.
- React Bits Animated List and Magic Bento: restrained new-event highlighting
  and reduced-motion handling. No package or proprietary component code was
  copied; the existing CSS event pulse remains the only feed animation.

The current logo is retained unchanged. No sample prices, wallets, candles or
rewards are used to fill unavailable states.
