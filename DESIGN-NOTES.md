# Topblast interface direction

## October 2026 premium pass

The homepage now uses a charcoal market canvas (`#0B0E0C`), neutral trading
surfaces and electric lime only for actions and verified positive state. Coral
is reserved for underwater positions. The hero, three live metrics, chart and
wallet inspector establish the complete product before the supporting ledger
and rules. On mobile, the chart precedes wallet details and secondary totals
move into the reward ledger to reduce page height.

Reference review:

- 21st.dev Market Chart and Balance Chart informed the compact tool grouping,
  crosshair-first presentation and visible metric hierarchy. The site retains
  its existing licensed TradingView Lightweight Charts renderer and real data.
- React Bits Animated List informed the brief new-event emphasis. No component
  package or sample activity was copied; Topblast keeps its existing CSS pulse,
  finalized-event gate and reduced-motion fallback.

No pricing, cost basis, eligibility, epoch or payout behavior changed in this
pass. Unavailable values remain unavailable rather than being filled with demo
data.

The production interface uses one deep emerald trading surface, thin borders,
off-white financial typography and lime only for primary actions and positive
market state. Coral remains reserved for underwater positions.

Reference review:

- 21st.dev Web3 Bento: compact live metrics and explicit data hierarchy. The
  Topblast implementation keeps the density and hierarchy while avoiding its
  decorative card stack.
- 21st.dev Stock Market Tracker: chart-first responsive control grouping. The
  existing TradingView Lightweight Charts implementation remains in place.
- React Bits Animated List and Magic Bento: restrained new-event highlighting
  and reduced-motion handling. No package or proprietary component code was
  copied; the existing CSS event pulse remains the only feed animation.

The current logo is retained unchanged. No sample prices, wallets, candles or
rewards are used to fill unavailable states.

October 31 polish: preserved the existing chart, logo and data providers. The
[21st Market Chart](https://mcp.21st.dev/%40arihantcodes_1f7b8c4d/components/market-chart)
